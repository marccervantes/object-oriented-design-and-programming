# Object-Oriented Design and Programming

This repository contains coursework, programming assignments (PECs), and practical exercises completed as part of the **Object-Oriented Design and Programming** course at the **Universitat Oberta de Catalunya (UOC)**.

## 📖 Overview

This course focuses on object-oriented programming principles, software design, and practical development using Java.
